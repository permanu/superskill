# Go - Sources

Baseline: latest
Last verified: 2026-10-05

Traceability: the cited standard-library pages currently render for go1.27.1, the release-notes page currently documents Go 1.27, and x/sync errgroup currently shows v0.23.0. This note records what the sources showed at authoring time; rules never pin versions.

## Primary

1. [Effective Go](https://go.dev/doc/effective_go) - core idioms: error values, multiple returns, defer/panic/recover, slices, type assertions, embedding, receivers, defer-close (err, io, conc, style, anti, type, conv)
2. [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments) - error strings, handling errors, contexts, goroutine lifetimes, interfaces (err, conc, iface, style)
3. [Go FAQ](https://go.dev/doc/faq) - nil error semantics, generics rationale, maps and references (err, type, gen, mem)
4. [Google Go Style Guide](https://google.github.io/styleguide/go/) - readability foundation; decisions and best-practices subpages (style, err, test, doc)
5. [Package errors](https://pkg.go.dev/errors) - Is, As, AsType, Join, Unwrap semantics (err)
6. [Package context](https://pkg.go.dev/context) - cancellation, deadlines, first-parameter, storage, and value-scope rules (err, conc, net, anti)
7. [Package log/slog](https://pkg.go.dev/log/slog) - structured logging, contexts, attributes, performance notes (obs, err)
8. [Working with Errors in Go 1.13](https://go.dev/blog/go1.13-errors) - when to wrap, sentinels, errors as API contract (err, api)
9. [Error handling and Go](https://go.dev/blog/error-handling-and-go) - error types, in-band errors, repetitive handling (err)
10. [Fixing For Loops in Go 1.22](https://go.dev/blog/loopvar-preview) - per-iteration loop variables, closure capture (conc, mem, test)
11. [When To Use Generics](https://go.dev/blog/when-generics) - generics decision rules, functions over methods (gen)
12. [Go Release Notes](https://go.dev/doc/go1.27) - current language, toolchain, vet, and library changes (all)
