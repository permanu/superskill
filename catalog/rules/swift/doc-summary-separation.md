> Separate the summary from additional discussion with a blank comment line.

## Why

The API Design Guidelines define the summary as the first paragraph and require later paragraphs to be separated by blank lines. Renderers treat the text before the first blank line as the abstract shown in symbol lists; when discussion runs on without a blank line, the summary and the detail merge into one paragraph and the abstract becomes the whole comment.

## Bad

```swift
/// Writes the textual representation of each element of `items` to the standard output.
/// The textual representation for each item `x` is generated by the expression `String(x)`.
func printItems(_ items: [Int]) {
    for item in items {
        print(item)
    }
}
```

## Good

```swift
/// Writes the textual representation of each element of `items` to the standard output.
///
/// The textual representation for each item `x` is generated by the expression `String(x)`.
func printItems(_ items: [Int]) {
    for item in items {
        print(item)
    }
}
```
