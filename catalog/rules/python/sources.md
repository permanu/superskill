# Python - Sources

Baseline: latest

Last verified: 2026-10-05

Source snapshot (traceability only, never pinned in rules): the cited docs.python.org pages currently serve the 3.14.x documentation; PEP and Ruff pages are versionless. Compile checks during authoring ran on the local CPython 3.14.6.

## Primary

1. [The Python Tutorial](https://docs.python.org/3/tutorial/index.html) - baseline idioms and language tour (conv, style, data, io)
2. [The Python Tutorial - Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html) - raising, chaining, clean-up, groups, notes (err)
3. [Built-in Exceptions](https://docs.python.org/3/library/exceptions.html) - hierarchy, context attributes, TypeError/ValueError split (err, api)
4. [contextlib - Utilities for with-statement contexts](https://docs.python.org/3/library/contextlib.html) - context managers, suppress, ExitStack, closing (err, io, mem)
5. [typing - Support for type hints](https://docs.python.org/3/library/typing.html) - annotations, generics, Protocols, type aliases (type, api, pat)
6. [asyncio - Coroutines and Tasks](https://docs.python.org/3/library/asyncio-task.html) - tasks, cancellation, TaskGroup, timeouts, threads (async, err, conc)
7. [PEP 654 - Exception Groups and except*](https://peps.python.org/pep-0654/) - grouped failures, subgroup/split semantics (err, async)
8. [PEP 3134 - Exception Chaining and Embedded Tracebacks](https://peps.python.org/pep-3134/) - __cause__, __context__, implicit chaining (err)
9. [PEP 678 - Enriching Exceptions with Notes](https://peps.python.org/pep-0678/) - add_note for context without changing type (err, obs)
10. [warnings - Warning control](https://docs.python.org/3/library/warnings.html) - warning categories, filters, deprecations (err, api)
11. [logging - Logging facility for Python](https://docs.python.org/3/library/logging.html) - logger.exception, records, levels, threading (obs, err)
12. [Google Python Style Guide](https://google.github.io/styleguide/pyguide.html) - exception policy, docstrings, imports, style (style, doc, err, api)
