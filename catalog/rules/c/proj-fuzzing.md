> Give every parser an entry point that takes `(data, length)` and returns without side effects.

## Why

A coverage-guided fuzzer explores a function by calling it with generated byte sequences, which requires an interface that accepts a buffer and a length and does no I/O of its own. Parsers that read directly from a stream or global cannot be driven at scale. Extracting the parse logic into a pure function makes it fuzzable and leaves a thin wrapper for real input.

## Bad

```c
#include <stdio.h>

int parse_header(void) {
    unsigned char buf[16];
    if (fread(buf, 1, sizeof buf, stdin) != sizeof buf) {
        return -1;   /* input is hard-wired to stdin: hard to fuzz */
    }
    return buf[0];
}
```

## Good

```c
#include <stddef.h>

int parse_header(const unsigned char *data, size_t len) {
    if (data == NULL || len < 16) {
        return -1;   /* pure entry point a fuzzer can drive */
    }
    return data[0];
}
```
