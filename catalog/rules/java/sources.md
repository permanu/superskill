Traceability: API pages were fetched from the Java SE documentation site; JEP statuses were read from the OpenJDK JEP index on the verification date. The authoring toolchain is javac 23.0.2; current stable releases are newer, so rules use `baseline: latest` and avoid APIs that are not yet stable.

## Primary

1. [Java SE API Specification](https://docs.oracle.com/en/java/javase/23/docs/api/index.html) - API signatures and behavioral contracts across all prefixes
2. [The Java Language Specification, Java SE 23 Edition](https://docs.oracle.com/javase/specs/jls/se23/html/index.html) - language semantics for type, err, pat, conc, const
3. [OpenJDK JEP Index](https://openjdk.org/jeps/) - feature status and evolution; separates stable features from preview APIs
4. [JEP 395: Records](https://openjdk.org/jeps/395) - records as transparent carriers for immutable data (type, api, data)
5. [JEP 409: Sealed Classes](https://openjdk.org/jeps/409) - closed hierarchies and compile-time exhaustiveness (type, pat, api)
6. [JEP 441: Pattern Matching for switch](https://openjdk.org/jeps/441) - type patterns, guards, exhaustiveness, null labels (pat, type)
7. [JEP 444: Virtual Threads](https://openjdk.org/jeps/444) - thread-per-task style, pinning, virtual thread API surface (conc, err, obs)
8. [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) - naming, formatting, caught exceptions, Javadoc (style, doc, err)
9. [Java Tutorials: The Exceptions Trail](https://docs.oracle.com/javase/tutorial/essential/exceptions/index.html) - checked/unchecked guidance, chaining, try-with-resources (err)
10. [Throwable API](https://docs.oracle.com/en/java/javase/23/docs/api/java.base/java/lang/Throwable.html) - causes, suppressed exceptions, wrapping rationale (err, api)
11. [Optional API](https://docs.oracle.com/en/java/javase/23/docs/api/java.base/java/util/Optional.html) - intended use as a return type for absent results (opt, api, err)
12. [Error Prone bug patterns](https://errorprone.info/bugpatterns) - tool checks cited by `enforce: tool` rules (lint, err)
