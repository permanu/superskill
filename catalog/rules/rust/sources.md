# Rust - Sources

Baseline: latest
Last verified: 2026-10-14 (metadata URLs only)

## Primary

1. [Rust Reference](https://doc.rust-lang.org/reference/) - language semantics for type, trait, own, closure, macro, const, pat, name, and unsafe.
2. [Rust standard library](https://doc.rust-lang.org/std/) - ownership, borrowing, collections, memory, errors, conversions, atomics, threading, numeric operations, and testing APIs.
3. [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/) - api, name, trait, conv, doc, and public-interface conventions.
4. [Rustonomicon](https://doc.rust-lang.org/nomicon/) - unsafe contracts, memory layout, aliasing, ownership, and concurrency safety.
5. [Clippy documentation](https://doc.rust-lang.org/clippy/) - lint, anti, style, and tool-enforcement references; individual rules must name the specific lint they claim.
6. [Cargo Reference](https://doc.rust-lang.org/cargo/reference/) - proj, dependency configuration, features, profiles, build tooling, and optimization configuration.
7. [Asynchronous Programming in Rust](https://rust-lang.github.io/async-book/) - async execution, futures, task lifecycle, and concurrency concepts.
8. [Tokio crate documentation](https://docs.rs/tokio/latest/tokio/) - runtime-specific async, cancellation, synchronization, channels, and task APIs.
9. [Serde documentation](https://serde.rs/) - serde derives, attributes, serialization formats, and data-model decisions.
10. [The rustdoc book](https://doc.rust-lang.org/rustdoc/) - doc comments, doctests, links, visibility, and documentation generation.
