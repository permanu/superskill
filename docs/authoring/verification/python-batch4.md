|---|---|---|
| python-sec-assert-not-enforcement | verified | Google pyguide: "Do not use assert statements in place of conditionals... They must not be critical to the application logic. A litmus test would be that the assert could be removed without breaking the code." Run: normal `may_read('bob')` raises `AssertionError`; `python3 -O` returns `True` (assert stripped); Good raises `PermissionError` in every mode. |
| python-sec-compare-digest | verified | hmac docs: "compare_digest() function instead of the == operator"; "timing analysis by avoiding content-based short circuiting behaviour"; str (ASCII only) or bytes-like, same type. | python-sec-hash-integrity | verified | hashlib: "Some algorithms have known hash collision weaknesses (including MD5 and SHA1)"; Ruff S324 targets `md4, md5, sha, sha1`. Run: md5 32 hex, sha256 64 hex; `sha256(b"abc")` matches the known vector. |
| python-sec-no-hardcoded-secrets | verified | Ruff S105: "Including a hardcoded password in source code is a security risk...
