## Source verification (claim -> passage)

- **io**: "EOF is the error returned by Read when no more input is available"; "Read must return EOF itself, not an error wrapping EOF, because callers will test for EOF using =="; "return EOF only to signal a graceful end of input"; unexpected EOF -> "ErrUnexpectedEOF or some other error giving more detail"; ReadAll "reads from r until an error or EOF", "successful call returns err == nil, not err == EOF", Reader "process the n > 0 bytes returned before considering the error err"; "Read reads up to len(p) bytes", "conventionally returns what is available instead of waiting for more"; ReadFull "reads exactly len(buf) bytes"; NopCloser "returns a ReadCloser with a no-op Close method wrapping the provided Reader r", "ReadCloser is the interface that groups the basic Read and Close methods" (plus WriterTo forwarding); SeekStart/SeekCurrent/SeekEnd definitions ("SeekStart means relative to the start of the file..."); Discard "Writer on which all Write calls succeed without doing anything"; Writer "must return a non-nil error if it returns n < len(p)"; LimitReader "reads from r but stops with EOF after n bytes".
- **os**: "Args holds the command-line arguments, starting with the program name"; Exit "Conventionally, code zero indicates success, non-zero an error"; "Open opens the named file for reading"; SEEK_SET/SEEK_CUR/SEEK_END with "Deprecated: Use io.SeekStart, io.SeekCurrent, and io.SeekEnd."
- **flag**: Parse "parses the command-line flags from os.Args[1:]", "Must be called after all flags are defined and before flags are accessed by the program"; Args "returns the non-flag command-line arguments"; ExitOnError "Call os.Exit(2) or for -h/-help Exit(0)"; syntax "-flag=x / -flag x", "One or two dashes may be used"; "Flag parsing stops just before the first non-flag argument ... or after the terminator `--`."
- **net/http**: Request.Context "For incoming server requests, the context is canceled when the client's connection closes, the request is canceled (with HTTP/2), or when the ServeHTTP method returns"; NewRequestWithContext "the context controls the entire lifetime of a request and its response: obtaining a connection, sending the request, and reading the response headers and body", NewRequest "wraps NewRequestWithContext using context.Background"; Body "For server requests, the Request Body is always non-nil but will return EOF immediately when no body is present"; Shutdown "gracefully shuts down the server without interrupting any active connections", "first closing all open listeners, then closing all idle connections, and then waiting indefinitely for connections to return to idle"; ErrServerClosed returned by Serve/ListenAndServe "after a call to Server.Shutdown"; Close "immediately closes all active net.Listeners"; ReadHeaderTimeout "amount of time allowed to read request headers", "If zero, the value of ReadTimeout is used.
